Some artifacts are intentionally generated by running the pipelines because the assignment requires outputs to reflect the execution environment:

- `data_pipeline/books_clean.csv`
- `data_pipeline/zepto_books.db`
- `analytics/titanic.csv`

- `analytics/model_pipeline.joblib`

Run the module scripts/notebooks to create them. This avoids fabricating model metrics or scraped live-data results before execution.
